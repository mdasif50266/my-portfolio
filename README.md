# Md Asif — Personal Portfolio

A modern, responsive personal portfolio website built to showcase my skills, services, projects, and software/automation solutions.

## 🚀 Live Website

Coming soon...

## ✨ Features

- Modern responsive design
- Home, Services, Projects, Demos, Automation, About and Contact sections
- Contact form with frontend validation
- Contact submissions stored in Supabase
- Service and budget selection
- Responsive navigation
- Project showcase
- Automation and AI solution sections
- Dark modern UI
- Smooth page navigation
- Mobile-friendly layout

## 🛠️ Tech Stack

- **Next.js 16**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **Supabase**
- **Git & GitHub**
